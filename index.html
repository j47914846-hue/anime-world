About Anime World

Anime World is a fan-built hub for discovering series across every genre imaginable — from high-octane shonen battles to cozy slice-of-life stories. Our mission is simple: help you find the next show you'll love, learn about the characters that shaped the medium, and keep up with what's happening in the anime industry. This project is a demo built with HTML, CSS, and JavaScript to showcase responsive, interactive front-end design.
